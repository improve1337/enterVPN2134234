# Рассылка поста из админки

Документ описывает, как админ пишет пост и отправляет его всем пользователям
бота. Актуально на 8 ноября 2026.

---

## 1. Как это работает для админа

«🛠 Админка» → **«📣 Рассылка»** → бот просит текст поста.

1. Отправьте сообщение — **текст** или **картинку с подписью** (подпись станет
   текстом поста; картинка без текста тоже допустима).
2. Бот показывает **предпросмотр** — ровно то, что увидят пользователи, плюс
   кнопки «✅ Отправить всем (N)» и «❌ Отмена».
3. Нажмите «✅» — бот отправит пост всем и покажет итог:
   сколько получателей, сколько доставлено и сколько не доставлено.

Отмена — кнопка «❌» или любая кнопка меню.

---

## 2. Кому уходит

Всем пользователям из таблицы `users`, **кроме забаненных** в боте.

Те, кто сам заблокировал бота, остаются в списке — Telegram вернёт ошибку
доставки, и она попадёт в счётчик «не доставлено». Так админ видит реальную
картину, а не молчаливую потерю части аудитории.

---

## 3. Нюансы отправки

| Нюанс | Как решено |
|---|---|
| Лимиты Telegram (~30 сообщений в секунду) | пауза 50 мс между отправками (`delayMs`) |
| Ответ `429 Too Many Requests` | ждём `retry_after` из ответа и повторяем отправку один раз |
| Пользователь заблокировал бота (`403`) | считаем как «не доставлено», рассылка продолжается |
| Большая аудитория | сообщение «Отправляю N получателям…» заменяется итогом по завершении |
| Черновик | хранится в памяти бота; перезапуск между предпросмотром и отправкой его теряет (начните заново) |

В `audit_log` пишется запись `broadcast` с результатом (`sent=X/Y`).

## 4. Код

| Файл | Что |
|---|---|
| `src/services/broadcast.ts` | `broadcastMessage()`: список получателей, пауза, обработка 429/403, счётчики |
| `src/db.ts` | `listBroadcastRecipients()` — все, кроме забаненных |
| `src/ui/keyboards.ts` | кнопка «📣 Рассылка» в админке, `broadcastPreviewKeyboard` |
| `src/ui/texts.ts` | тексты промпта, предпросмотра и итога |
| `src/bot.ts` | состояние `broadcast_compose`, колбэки `adm:broadcast`, `bc:send`, `bc:cancel` |
| `tests/broadcast.test.ts` | 6 тестов: получатели, ошибки доставки, фото, прогресс, пустая база |

---

## 5. Как проверить

```bash
cd bot
npm run typecheck
npm test          # 59 тестов, из них 6 — рассылка
```

В Telegram:

1. «🛠 Админка» → «📣 Рассылка».
2. Отправьте текст (или картинку с подписью).
3. Проверьте предпросмотр → «✅ Отправить всем».
4. Дождитесь итога: «Доставлено: X, Не доставлено: Y».
